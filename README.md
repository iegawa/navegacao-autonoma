# Navegação autônoma: do sensor à ação

Página interativa para aula introdutória de navegação autônoma: sensores, localização, mapeamento, planejamento e controle, com três níveis de complexidade (sala estática, ambiente dinâmico e carro com GNSS).

Abra `index.html` no navegador ou acesse a versão publicada pelo GitHub Pages.

## Simulador: pose, twist e derivadas

`simulador-pose-twist/` traz um simulador interativo, em 2D (TurtleBot) e 3D (avião), que mostra posição, orientação, pose, twist no corpo, twist espacial e derivada das coordenadas, com os referenciais global {W} e local {B}.

## Aula 3: Pose, transformações e odometria

`aula-03/` traz os slides interativos da Aula 3 (pose 2D/3D, referenciais, transformações homogêneas, twist, restrição não holonômica, sensores e odometria), com checkpoints e notas do professor (tecla N).
